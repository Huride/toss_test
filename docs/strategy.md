# 전략 설계 문서 — 미국주식 스윙 자동매매

> 대상: 미국 주식(NYSE/NASDAQ) · 보유기간 며칠~몇 주(스윙) · 일봉 기반
> 데이터: 토스증권 Open API(가격) + (옵션) 외부 뉴스/이벤트
> 본 문서는 구현·백테스트의 기준 스펙입니다.

---

## 1. 전체 구조

```
        ┌──────────────┐
가격 ──▶ │ 가격 전략 코어 │ ── 1차 신호(진입/청산/손절) ─┐
(토스)   │ (돈치안 돌파)  │                              │
        └──────────────┘                              ▼
                                               ┌──────────────┐
뉴스 ──▶ NewsProvider ──▶ AIScorer(Claude 패널) │ 신호 결합/필터 │ ─▶ 주문
(옵션)                    방향/확신도/재료중요도   └──────────────┘
```

- **가격 코어가 검증된 본체.** 외부 의존 0으로 단독 동작.
- **뉴스/AI는 오버레이(필터·가드).** 켜고 끌 수 있고, 성과를 베이스라인과 비교 측정.

---

## 2. 가격 전략 코어 — 돈치안 돌파 추세추종

### 유니버스
- 유동성 큰 미국 종목/ETF 관심리스트(예 20~50개).
- 일평균 거래대금 하한 필터로 저유동성 제외.

### 진입 (롱)
- **추세필터**: `종가 > SMA(200)` (장기 상승추세 종목만)
- **돌파**: `종가 ≥ 최근 20일 최고가(당일 제외)`
- 두 조건 동시 충족 → **다음 거래일 시가 매수** (look-ahead 방지)

### 청산
- `종가 ≤ 최근 10일 최저가` → 전량 청산 (돈치안 트레일링)

### 손절
- 진입가 − `2 × ATR(14)` 도달 시 청산.
- 토스에 stop 주문이 없으므로 **봇이 매일 폴링하며 직접 트리거.**

### 포지션 사이징 (리스크 기반)
- 트레이드당 리스크 = 계좌자산 × `R`(기본 1%).
- `매수금액 = (계좌자산 × R) ÷ (2·ATR ÷ 진입가)`
- 미국주 **금액주문(소수점)** 으로 정밀 배분.
- 동시 보유 최대 `N`종목(기본 8), 종목당 비중 상한(기본 20%).

### 파라미터 기본값
| 이름 | 값 | 의미 |
|---|---|---|
| `entry_lookback` | 20 | 돌파 신고가 기간 |
| `exit_lookback` | 10 | 트레일링 청산 기간 |
| `trend_ma` | 200 | 추세필터 SMA |
| `atr_period` | 14 | ATR 기간 |
| `atr_stop_mult` | 2.0 | 손절 ATR 배수 |
| `risk_per_trade` | 0.01 | 트레이드당 리스크 비중 |
| `max_positions` | 8 | 동시 보유 한도 |
| `max_weight` | 0.20 | 종목당 비중 상한 |

## 3. 뉴스/AI 오버레이 (옵션, MiroFish식 다관점 해석)

### 발상
MiroFish(멀티에이전트 사회 시뮬)의 "뉴스를 다관점으로 해석" 아이디어를 **경량화**:
풀 시뮬레이션 엔진 대신, **Claude 다관점 패널**(낙관/비관/리스크매니저)이 뉴스+가격 맥락을
평가해 구조화 점수를 산출 → **필터/가드로만** 사용.

### 산출 (AIScorer)
```json
{
  "direction": "bullish | neutral | bearish",
  "conviction": 0.0,        // 0~1
  "materiality": 0.0,       // 재료 중요도 0~1
  "rationale": "요약"
}
```

### 사용 방식 (포지션을 키우지 않고, 거르기만)
- **어닝 가드**: 실적발표 1~2일 전 신규진입 금지(옵션: 발표 전 청산).
- **악재 가드**: `bearish & materiality 높음` → 신규진입 보류 / 포지션 축소.
- **확신 게이트**: 돌파 신호라도 AI가 강한 악재면 스킵.
- ⚠️ AI 단독으로 매수/사이징 결정 금지. 가격 코어 보조 역할만.

### 결정성·비용 통제
- temperature 낮게, **입력 해시 기반 캐싱**(같은 입력=같은 점수, 재현 가능).
- 종목·기간 좁혀 비용 통제.

## 4. 백테스트 방법론 — 히스토리컬 리플레이

뉴스 기반 신호는 **point-in-time 리플레이**로만 정직하게 검증된다.

### 루프 (각 날짜 t)
1. t 시점까지 알 수 있었던 가격·뉴스만 추출 (**미래참조 금지**)
2. 가격 코어 신호 계산 (종가 기준)
3. (옵션) AIScorer로 뉴스 점수화
4. 신호 결합 → 익일 시가 체결 가정으로 매매 시뮬
5. 성과 기록

### 반드시 통제할 편향
- **look-ahead**: 신호=종가, 체결=익일 시가. 지표는 t까지 데이터만.
- **survivorship**: 상장폐지 종목 포함 유니버스.
- **뉴스 가용성**: 다년치는 GDELT(무료) 또는 유료 아카이브. 무료 최신 API는 백테스트 부적합.
- **거래비용**: 수수료·슬리피지 반영(토스 `/commissions` 참고).
- **LLM 비결정성**: 캐싱으로 재현성 확보.

### 성과 지표
CAGR · MDD(최대낙폭) · Sharpe · 승률 · 손익비 · 거래횟수.
**가격-온리 vs AI-오버레이** 를 같은 기간으로 비교해 오버레이의 실효를 측정.

## 5. 단계별 로드맵
1. **백테스트 하네스(가격-온리)** — 합성/실데이터로 돈치안 검증·파라미터 튜닝. ← 현재 단계
2. **실데이터 연결** — 토스 일봉 페이지네이션으로 과거 데이터 적재.
3. **뉴스/AI 오버레이** — `NewsProvider`+`AIScorer` 추가, 리플레이로 효과 측정.
4. **봇 스켈레톤** — 토큰관리·폴링루프·주문래퍼에 전략 모듈 탑재.
5. **페이퍼 → 소액 라이브.**
